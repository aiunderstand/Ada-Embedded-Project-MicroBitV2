micro:bit v2 serial console

Reads Put_Line output from your Ada program over USB — nothing to install.

This browser cannot talk to the micro:bit

Web Serial works in Chrome, Edge and Opera on desktop. Safari and Firefox do not implement it, and there is no polyfill.

You can still see output by flashing the board and using the serial monitor in VS Code instead.

  • Use the cable that came with the board — some charge-only USB cables carry no data.

  • Linux: add yourself to the dialout group
          (sudo usermod -aG dialout $USER, then log out and back in).
          Chromium installed as a snap cannot use Web Serial at all; install the
          .deb build instead.
    • 
      
  • Close anything else holding the port — VS Code's serial monitor, or a running
          pyocd.
