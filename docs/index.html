Flash your Ada program and read its output — straight from the browser, nothing to install.

This browser cannot talk to the micro:bit

WebUSB works in Chrome, Edge and Opera on desktop. Safari and Firefox do not implement it, and there is no polyfill.

You can still flash without any browser support: drag main.hex onto the MICROBIT drive that appears when you plug the board in.

If Connect shows no devices

    
    
      
  • Use the cable that came with the board — some charge-only USB cables carry no data.
    • 
      
  • Linux: install the udev rule shipped in the repository, or the browser
          cannot open the device:
          sudo cp tools/udev/50-microbit.rules /etc/udev/rules.d/ then
          sudo udevadm control --reload-rules && sudo udevadm trigger.
          Chromium installed as a snap cannot reach USB devices at all; use the
          .deb build.
    • 
      
  • Close anything else holding the board — a running pyocd, or another tab
          with this page open. WebUSB claims the debug interface exclusively.
    • 
    

  


  

    Flashing and serial share one connection: WebUSB talks to the board's DAPLink interface chip,
    which is separate from the nRF52833 running your program — so the connection survives a flash
    and output resumes on its own.
